# 3D Custom Models Directory

You can place your own 3D models (`.glb` or `.gltf` format) into this folder to replace the procedural models!

Supported filenames:
- `house1.glb` — Replaces Villa Type 1
- `house2.glb` — Replaces Villa Type 2
- `house3.glb` — Replaces Villa Type 3
- `tree.glb`   — Replaces the cartoon trees
- `character.glb` — Replaces the 3D explorer character

### Best practices for models:
- Format: `.glb` (Binary glTF)
- Scale: Real-world meters (e.g. 1 unit = 1 meter; a 2-story house is ~7m tall)
- Texture/Material: Pastel colors with low roughness for the cartoon/clay aesthetic
